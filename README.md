# TaskFlow — Этап 3 (Проекты, участники и ролевая модель)

## Что реализовано на Этапе 3
- Создание проектов только подтверждёнными преподавателями (`@RequireVerifiedTeacher()`)
- Автоматическое назначение создателя единственным руководителем проекта (`leaderId = creatorId`, роль `LEADER`) без возможности передачи руководства
- Редактирование, архивация и удаление проекта руководителем
- Добавление зарегистрированных участников по email или username с выбором роли (`MEMBER` — Участник, `OBSERVER` — Наблюдатель)
- Изменение ролей и удаление участников руководителем
- Серверная изоляция проектов и проверка ролей (`ProjectAccessGuard` + `@ProjectRoles`)
