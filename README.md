# TaskFlow — система управления учебными проектами

**TaskFlow** — это веб-приложение для студенческих команд и преподавателей, которое помогает организованно вести учебные и курсовые проекты без бесконечного хаоса в мессенджерах. Вся работа собрана в одном месте: проекты, распределение ролей, канбан-доска с задачами, дедлайны, комментарии, календарь и личный кабинет со сводкой по всем делам.

---

## Что уже умеет система

* **Роли и доступ без путаницы:**
  * На уровне всей системы есть **Студенты**, **Преподаватели** и **Системный администратор**. Новые преподаватели проходят проверку у администратора, после чего получают право создавать проекты.
  * Внутри каждого проекта назначаются локальные роли: **Руководитель** (управляет командой и проектом), **Участник** (работает с задачами) и **Наблюдатель** (смотрит прогресс без права редактирования).
* **Проекты и команды:**
  * Создание проектов со сроками, приглашение участников по логину или email, смена ролей, передача руководства и архивация завершённых проектов.
* **Канбан-доска и управление задачами:**
  * Шесть понятных колонок: *Новая*, *В работе*, *На проверке*, *Готово*, *Заблокировано* и *Отложено*.
  * Перетаскивание карточек мышкой (Drag-and-Drop), приоритеты, цветные метки, автоматическая подсветка просроченных дедлайнов и быстрая фильтрация.
* **Обсуждение внутри задач:**
  * Живая лента комментариев в карточке каждой задачи с возможностью редактировать и удалять свои сообщения.
* **Личный кабинет и календарь задач:**
  * Единый экран со статистикой по всем проектам и задачам пользователя.
  * Переключение между привычным **списком** и интерактивным **календарём** по месяцам, где сразу видно, на какой день назначены дедлайны, какие задачи просрочены и какие задачи пока идут без срока.

## Как устроен проект (стек технологий)

Проект организован в виде монорепозитория (`apps/backend` + `apps/frontend`):

* **Сервер (`apps/backend`):** Python, FastAPI, SQLAlchemy 2.0, Pydantic. Пароли хешируются через Argon2id, а авторизация работает на серверных сессиях с защищёнными `HttpOnly` cookies.
* **Клиент (`apps/frontend`):** React 18, TypeScript, Vite, Tailwind CSS и TanStack Query.
* **База данных:** PostgreSQL 16 в Docker-контейнере.

## Как запустить локально

### 1. Поднять базу данных PostgreSQL
Из корневой папки `taskflow`:
```bash
docker compose up -d
```

### 2. Настроить окружение и запустить сервер
Убедись, что в корне проекта (или в `apps/backend/.env`) создан файл `.env` с параметрами подключения:
```env
DATABASE_URL=postgresql://taskflow:taskflow@localhost:5432/taskflow
SESSION_SECRET=super_secret_key_minimum_16_chars
FRONTEND_URL=http://localhost:5173
AUTO_APPROVE_TEACHERS=false
```

Запуск бэкенда:
```bash
cd apps/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 3000
```
Интерактивная документация API (Swagger) после запуска доступна по адресу: `http://localhost:3000/api/v1/docs`.

### 3. Запустить фронтенд
Во второй вкладке терминала из корневой папки `taskflow`:
```bash
cd apps/frontend
npm install
npm run dev
```
После этого приложение откроется в браузере на `http://localhost:5173`.

### 4. Назначить системного администратора (если нужно)
Зарегистрируй обычный аккаунт на сайте, затем выполни из `apps/backend` (с активированным `.venv`):
```bash
python scripts/make_admin.py твой_логин_или_email
```
