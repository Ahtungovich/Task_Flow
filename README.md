### Этап 6. Комментарии к задачам (Backend + Frontend)
- Серверный модуль комментариев: добавление, просмотр ленты обсуждения в карточке задачи и удаление (автором комментария или руководителем проекта).
- Живой блок комментариев прямо внутри модального окна задачи (`TaskDetailsModal`) вместо заглушки, с автоматическим обновлением счётчика комментариев на карточках канбан-доски.
