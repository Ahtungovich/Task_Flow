# TaskFlow — Этап 7 (Агрегированный личный кабинет и завершение 50% MVP)

## Что реализовано на Этапе 7
- Новый эндпоинт `GET /api/v1/users/me/tasks` на Python (FastAPI + SQLAlchemy), возвращающий все назначенные текущему пользователю задачи из всех его проектов и сводную статистику (`total`, `active`, `inProgress`, `done`, `overdue`)
- Обновлённый личный кабинет (`DashboardPage`) с карточками статистики, фильтруемым списком «Мои задачи» (по статусу, проекту и признаку просрочки) и быстрым переходом прямо в карточку нужной задачи внутри проекта (`?taskId=...`)
- План 50% MVP (Этапы 1–7) полностью выполнен на стеке **React + Vite / Python + FastAPI + SQLAlchemy / PostgreSQL + Docker**
