# TaskFlow — Этап 2 (Регистрация, авторизация и профиль)

Адаптивное веб-приложение для совместного планирования задач и управления учебными проектами.

## Что реализовано на Этапе 2
- Регистрация пользователя (`Студент` или `Преподаватель`) с проверкой уникальности `email` и `username`
- Хеширование паролей алгоритмом **Argon2id**
- Серверные сессии в PostgreSQL + защищённые `HttpOnly` cookies
- Вход по `email` или `username`, выход из системы с удалением сессии
- Защита маршрутов на сервере (`SessionAuthGuard`) и на клиенте (`ProtectedRoute`, `GuestOnlyRoute`)
- Просмотр и редактирование профиля (`fullName`, `username`, `avatar`), смена пароля
