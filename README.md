# TaskFlow — Этап 5 (Канбан-доска с 6 статусами, список задач и карточка задачи)

## Что реализовано на Этапе 5
- Канбан-доска внутри проекта с 6 колонками (`Новая`, `В работе`, `На проверке`, `Готово`, `Заблокировано`, `Отложено`)
- Перенос задач между статусами перетаскиванием (Drag & Drop) или через выпадающий селектор на карточке
- Переключение между режимом канбан-доски и табличным списком задач
- Фильтрация задач по названию, приоритету, исполнителю, меткам и признаку просрочки
- Управление метками проекта (создание/удаление цветных тегов руководителем)
- Модальные окна создания задачи и детальной карточки задачи с учётом прав роли (`LEADER`, `MEMBER`, `OBSERVER`)
